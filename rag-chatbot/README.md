# AI Tutor 🧠

Personalized AI tutor for Science (Classes 8-10).  
Ask questions, get hints, take quizzes, and track your progress!

## ✨ Features

- 📖 **Explain** – Get personalized answers
- 💡 **Hint** – 3 levels of hints
- 📝 **Quiz** – Auto-generated quizzes with answer key
- 📊 **Progress** – Track weak & mastered topics
- 🎯 **Recommend** – What to study next
- 🔄 **Compare** – Compare across Class 8, 9, 10

## 🚀 Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/DevrajThokchom/rag-chatbot.git
cd rag-chatbot

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate      # Mac/Linux
venv\Scripts\activate         # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up API key (create .env file)
OPENROUTER_API_KEY=your-api-key-here

# 5. Run the AI Tutor
python run.py
